# Corel Tools Suite - Agent Instructions & Project Rules

## Git & GitHub Release Rules
- STRICT RULE: JANGAN PERNAH publish, release, atau push release ke GitHub KECUALI jika pengguna secara eksplisit meminta/menginstruksikannya (contoh: "publish ke github", "upload ke github", "release ke github").
- Jika pengguna TIDAK bilang atau tidak meminta publish ke GitHub, SEMUA proses build, compile, dan pengujian harus TETAP berada di lingkungan lokal (di folder `dist-release/`, `publish/`, atau folder lokal seperti `Downloads`).
- Tunggu konfirmasi dan perintah jelas dari pengguna sebelum menyentuh rilis publik GitHub.

## Formatting & Code Rules
- Rule R-02: Dilarang keras menggunakan em-dash (—) atau en-dash (–) di seluruh teks antarmuka pengguna, log, dokumentasi, maupun kode. Gunakan tanda minus / strip biasa (-) saja.
